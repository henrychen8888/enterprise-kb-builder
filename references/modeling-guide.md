# 建模方法论：四层设计 + 一条生命周期

> 图片蓝图只解决"装哪些内容"。让知识库从资料仓库变成组织能力的，是下面四层设计。四条线不是严格先后，而是建设期同时考虑。

## 层次一：内容建模——从模块清单到可维护的知识条目

模块不能直接入库。需要把每个模块下的内容转化为**知识条目**：可独立检索、独立更新、有明确责任人的最小知识单元。

### 1. 四维交叉定位

用「业务域 × 文档类型 × 密级 × 时效」交叉定位，避免"按部门归档"陷阱（员工找答案时不知道去哪个部门翻）。定位后每类知识落到唯一责任人和明确更新节奏。示例：

- 「客户异议处理话术」：业务域=客户与沟通，文档类型=话术/FAQ，密级=内部，时效=随产品/政策更新。
- 「行业禁入红线」：业务域=行业与合规，文档类型=制度红线，密级=全员可见，时效=长期有效但需年度复核。

### 2. 拆条目，不是传文件

一份几十页的项目总结，员工很难判断哪一页适用。拆成「适用条件 + 判断逻辑 + 操作步骤 + 关联文档」的知识卡。34 个子模块最终落地为**数百到上千条**知识条目（原蓝图 1728 条即此量级）。

### 3. 必填元数据

至少包括：责任人、适用范围、生效/失效时间、来源文档、密级、关联模块。元数据是后续权限控制、过期清理、AI 检索过滤的基础。字段控制在维护者能稳定填写的数量（详见 assets/metadata-schema.md）。

## 层次二：隐性知识结构化萃取——把判断力变成可检索的知识

多数知识库最薄弱的一环。隐性经验**不能靠座谈会 + 几万字访谈记录**完成——产出的仍是无法检索的叙事文本。正确方法是围绕真实决策事件做结构化追问。

### 关键事件访谈 + 结构化追问框架

选一位老员工近期一个有代表性的判断（例如：某客户是否接受特殊账期、某项目风险是否值得冒、某竞品动作是否需要跟进），追问五维：

1. **当时看到了什么信号？**——哪些信息触发了判断
2. **考虑了哪些备选方案？**——不只是最终选择
3. **为什么排除了某些选项？**——被放弃的方案及原因，往往比最终选择更有信息量
4. **在什么条件下会改变这个判断？**——判断的边界条件
5. **如果新人只记住一句话，应该是什么？**——压缩为可检索的判断规则

产出不是访谈稿，而是**判断力知识卡**（模板见 assets/judgment-card-template.md）：场景 + 信号 + 判断规则 + 边界条件 + 反例/例外 + 责任人。可检索、可被 AI 引用、可被后续案例持续修订。

### 操作纪律

- 一次萃取一位员工的一个事件；一次访谈 2–3 个事件，宁精勿滥。
- 追问中被访者讲成故事时，随时拉回五维框架。
- 第 7 模块蓝图中的 56 条判断规则，应逐条按此逻辑萃取，不泛泛记"经验总结"。

## 层次三：生命周期治理——谁维护、多久复审、过期怎么办

知识库最常见的失败不是"建不起来"，而是建起来三个月后没人维护，AI 开始用旧制度回答新问题。治理机制必须**在建设阶段就嵌入**。

### 最小可运行治理规则

1. **唯一责任人**：不是"部门"，而是具体岗位或人。责任人对内容有效性负责，不是"上传过"。
2. **按变动频率定复审周期**：
   - 制度/合规类：年度复审，或政策变更触发
   - 产品/价格类：随版本更新
   - 客户案例/话术类：季度复审
   - 判断力知识卡：半年复审 + 新案例增补例外
   复审结论四选一：**继续有效 / 修订 / 过期下架 / 归档保留**。复审不是"再看一遍"。
3. **更新嵌入业务流程**，不依赖自觉：制度修订发布 → 自动触发对应条目复核；项目结项 → 自动归档经验文档并提示萃取判断卡；产品版本上线 → 同步更新价格与 FAQ。
4. **四个治理指标**（不追求复杂报表）：陈旧内容占比、待复核积压量、纠错反馈处理时长、核心场景问题覆盖率。

## 层次四：检索与 AI 就绪度——找得到，且敢被 AI 用

如果只给人浏览，结构清晰就够。若目标是 AI 基于知识库回答（RAG），需额外一层设计：

### 1. 文档清洗优先于模型选型

RAG 效果上限由数据质量决定，不是模型规模。页眉页脚、乱码、冲突旧版本、复杂表格错位都会导致答错。**财务/对比类表格必须转化为文字叙述或 QA 对**，否则 AI 极易读取错位。

### 2. 混合检索优于纯向量检索

企业场景既有模糊提问（"之前那个数据迁移方案怎么做的"）也有精确查询（合同编号、型号、条款号）。纯向量对精确术语不敏感。最佳实践：**向量检索 + 关键词检索 + 重排**。

### 3. 权限穿透到检索层

刚需不是"能不能搜到"，而是"不该看到的人搜不到"。权限对接统一身份认证（LDAP/OA），在**向量检索阶段就过滤无权切片**，不在答案生成后做表面拦截。

### 4. 回答可溯源

每条答案高亮回链到具体文档的具体章节。这既是治理幻觉的手段，也是让老员工愿意贡献判断依据的前提——他们能看到经验被准确引用，而不是被模型随意改写。
